03 · CASO DESTACADO

Vue Product Showcase

Descripción

SPA para un catálogo interactivo de productos. Permite visualizar productos, filtrar por categoría, consultar detalles y gestionar favoritos mediante una arquitectura de componentes.

Desafío principal

Construir una aplicación modular y mantenible que manejara datos externos, estado global y navegación, manteniendo además una experiencia funcional cuando la fuente de datos no estuviera disponible.

Solución

Se implementaron componentes reutilizables, Vuex para el estado, Vue Router para navegación, Element Plus para la interfaz y una alternativa de datos local para mantener el catálogo operativo.

Herramientas técnicas

Vue 3, Vue CLI, Vuex 4, Vue Router 4, Element Plus, JavaScript, Axios, Jest, Vue Test Utils y Cypress.

Impacto medible

  • 4 productos funcionales visibles en el catálogo final.
  • Filtrado por categoría y vista de detalle implementados.
  • Favoritos y gestión de estado centralizada.
  • 2 suites de pruebas unitarias con 4 pruebas ejecutadas correctamente.
  • 1 prueba end-to-end con Cypress.
  • Build de producción generado correctamente.

Aprendizajes y habilidades

Aprendí a estructurar una SPA por componentes, administrar estado global, trabajar con rutas, integrar librerías, probar funcionalidades y resolver fallos de integración de forma sistemática. También reforcé Git/GitHub y documentación técnica.

¿Por qué lo elegí?

Es el proyecto que mejor representa mi evolución hacia un perfil Front-End Junior porque reúne varias competencias en una solución completa: interfaz, lógica, datos, navegación, estado, pruebas, documentación y control de versiones.
